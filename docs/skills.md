# Agent Skills (SKILL.md Standard)

2026年現在、AIエージェントの能力を拡張するための標準的な手法は「スキル（Skills）」としてパッケージ化することです。

## 1. スキルとは？

スキルは、特定のタスク（例：コードレビュー、テスト生成、デプロイ等）を実行するための**「手順」「ツール」「規約」を一つにまとめたディレクトリ**です。
エージェントは必要に応じてこれらを「アクティブ」にし、その専門知識を利用します。

## 2. ディレクトリ構造

標準的なスキルは以下の構成をとります。

```text
.agents/skills/my-skill/
├── SKILL.md          # メインの指示書（YAMLフロントマター付き）
├── scripts/          # 自動化用スクリプト (Python, Node.js等)
├── references/       # 規約やテンプレート
└── assets/           # 関連アセット
```

## 3. SKILL.md の書き方

```markdown
---
name: security-auditor
description: "コード内の脆弱性や秘密鍵の露出をチェックし、修正案を提示します"
---
# 指針
1. `BeforeTool` フックと連携し、書き込み前にスキャンを実行する。
2. 脆弱性が発見された場合は、具体的なリスク（CWE等）を明記する。

# 手順
1. 修正されたファイルの差分を取得する。
2. セキュリティスキャンツールを実行し、結果をパースする。
...
```

## 4. ベストプラクティス

- **段階的開示:** スキルの詳細はエージェントがそれを選択した時にのみ読み込ませ、コンテキストを節約します。
- **ポータビリティ:** プロジェクトに依存しない汎用的なスキルとして設計し、`skills.sh` 等のツールで管理します。
- **設計優先:** 実装スキルを動かす前に、必ず `brainstorming` スキルで設計案の承認を得るワークフローを構築します。
