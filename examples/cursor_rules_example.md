# .cursorrules Example

このファイルをプロジェクトのルートに配置することで、CursorのAIエージェントに特定の指示を永続化できます。

```markdown
# Project Rules

## Tech Stack
- Frontend: Next.js 15 (App Router), Tailwind CSS
- Backend: Supabase (PostgreSQL)
- Language: TypeScript (Strict mode)

## Coding Standards
- Use functional components and hooks.
- Prefer `lucide-react` for icons.
- Ensure all components are responsive with Tailwind mobile-first approach.

## AI Instructions
- Always use `pnpm` for package management.
- Before creating a new component, check `src/components/ui` for existing Radix/Shadcn components.
- Write JSDoc comments for complex utility functions.
```
